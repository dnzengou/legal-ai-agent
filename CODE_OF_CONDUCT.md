# Code of Conduct

## Our standard

We want this project to be a productive, respectful place where people of every background can contribute. We optimise for high technical signal and low ego.

### What we value

- Clear, specific, kind feedback.
- Assuming good faith — most friction is a communication gap, not malice.
- Credit shared freely, criticism offered privately when possible.
- Focus on the work: the code, the docs, the behaviour of the software.

### What we don't tolerate

- Harassment, discrimination, or sustained personal attacks against contributors.
- Publishing others' private information without consent.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Report concerns privately via [private vulnerability reporting](https://github.com/dnzengou/legal-ai-agent/security/advisories/new) (we repurpose the channel for both security and conduct issues to keep them off the public tracker) or by direct message to the repository owner on GitHub.

The maintainer will:

1. Acknowledge the report within 72 hours.
2. Investigate and decide on an outcome within 14 days.
3. Communicate the outcome to the reporter, respecting confidentiality.

Possible outcomes range from a private clarifying conversation to a permanent ban from the project.

## Attribution

This Code of Conduct is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/) v2.1 but kept short and specific to this project's scale.
