Frequently asked questions

Short answers to the questions people actually ask before using legal-ai-agent. Every claim here maps to code or docs in the repository.

What is legal-ai-agent?

An open-source FastAPI service that reviews contracts, appeals, and legal documents, powered by Claude Opus 4.8. It returns extracted clauses, risks, compliance flags, recommendations, a 0–100 safety score, an A–F letter grade, and a glass-box 0–100 confidence score where every finding ships with a verbatim citation from the source.

How does it prevent hallucination?

Every risk and compliance flag must attach a verbatim text excerpt from the source document (up to 500 characters). The server performs exact-substring anchoring on each excerpt. A finding whose citation is not present character-for-character has its confidence forcibly downgraded to low, which drags down the overall_confidence score. The model proposes; the server verifies at the source level. Fabricated citations cannot score well because they cannot anchor. See src/agent.py → _anchor_clauses().

Is it free?

Yes. MIT licensed. You bring your own Anthropic API key. The only cost is whatever Anthropic charges for Claude Opus 4.8 inference per call, which scales with document length and the model's adaptive-thinking budget.

Does it replace a lawyer?

No. legal-ai-agent performs first-pass triage — identifying parties, term, key clauses, risks, and framework compliance. Judgment-heavy work like negotiation strategy, jurisdiction-specific case law research, and drafting counter-proposals still belongs with a licensed attorney. Every response ships with a disclaimer to that effect.

Is my document stored anywhere?

No. Contracts are processed in memory and discarded after the response. There is no database and no persistence layer in v0. If you self-host behind your own firewall, nothing leaves your infrastructure except the call to Anthropic's API.

What languages does it support?

Anything Claude Opus 4.8 reads fluently — including English, Swedish, French, German, Spanish, Portuguese, Italian, Dutch, and more. The landing-page demo includes a Swedish naturalization-appeal sample (svensk medborgarskap överklagan) to Migrationsverket.

What models does it use?

Claude Opus 4.8 (anthropic/claude-opus-4-8) with adaptive thinking enabled and output_config.effort set to high. Structured outputs are enforced via the Anthropic SDK's messages.parse() method, which validates every response against a strict JSON schema.

How is the safety score computed?

Server-side, deterministically. Start at 100. For each risk the model flags, deduct 20 points if high severity, 8 if medium, 3 if low. Clamp to [0, 100]. Letter grade: A if ≥ 90, B if ≥ 80, C if ≥ 70, D if ≥ 60, else F. The model is instructed to leave these fields null; it cannot inflate them. See src/scoring.py.

How is the confidence score computed?

Server-side, deterministically, as round(50 × anchor_rate + 50 × avg_self_confidence). Anchor rate is the fraction of findings whose verbatim citation is found in the source. Average self-confidence weights each finding at 1.0 for high, 0.6 for medium, 0.3 for low — unanchored findings are forcibly weighted at low. Buckets: high ≥ 80, medium ≥ 60, else low. See src/confidence.py.

Can I self-host?

Yes. A multi-arch Docker image is published to ghcr.io/dnzengou/legal-ai-agent on every push to main. It runs on any container host — Fly.io (pre-wired via fly.toml), Render, Railway, ECS, Cloud Run, Kubernetes, or a Raspberry Pi. Non-root user, HEALTHCHECK on /health. The Dockerfile targets both ARM64 and AMD64.

How is it different from ChatGPT, Claude, or Gemini directly?

Three practical differences. First, every finding attaches a verbatim quote anchored to the source — off-the-shelf chat cannot verify its own citations against your input. Second, the safety score and confidence score are deterministic and server-computed, so they are testable offline and immune to model drift. Third, it is a single-purpose API with a strict JSON schema, not a chat, so you can wire it into pipelines without parsing prose. For a deeper honest comparison with Harvey, CoCounsel, Kira, Luminance, Spellbook, and Ironclad, see POSITIONING.md.

How do I call the API?

POST /review with JSON body {"contract_text": "…", "jurisdiction": "optional", "party_role": "optional"} and an X-API-Key header. For PDF, POST /review-pdf with {"pdf_base64": "…"}. The full OpenAPI 3.1 spec is published at /openapi.json. A zero-dependency Python client ships in examples/client.py.

Is there a rate limit?

Yes — per-IP token-bucket limiting on /review and /review-pdf. Defaults: 30 requests per minute sustained, 60 burst. Tune via RATE_LIMIT_PER_MIN and RATE_LIMIT_BURST environment variables. /health and / are not rate-limited.

How do I cite legal-ai-agent in research?

Use the CITATION.cff at the repository root — Citation File Format 1.2.0, compatible with Zotero, Mendeley, GitHub's citation widget, and Zenodo.

Who is it for?

Creators (musicians, artists, writers, filmmakers) reviewing licensing and commissioning. Entrepreneurs (founders) reviewing term sheets, SAFEs, and customer MSAs. Builders (engineers) reviewing terms of service, DPAs, and API contracts. Consultants reviewing SOWs. SMB owners reviewing leases and employment agreements. Operators (GMs, procurement) reviewing vendor onboarding and SLAs. Also: individuals drafting administrative appeals, including naturalization appeals to Swedish Migrationsverket.
