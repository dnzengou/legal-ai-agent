        Illustrative output. Not legal advice — always confirm with a licensed attorney. The live API computes safety score server-side from the model's findings.

        How it works
        1. You paste a contract or appeal (text or PDF) — up to 500k chars.
        2. Claude Opus 4.8 (or DeepSeek / other LLM) runs a senior-attorney prompt with adaptive thinking and structured outputs.
        3. The server anchors every excerpt to your source and computes the safety score deterministically from the risks — the model can't inflate it.
        API & integration 
        # One endpoint · X-API-Key auth · JSON in/out
curl -X POST https://api.legal-ai-agent.fly.dev/review \
  -H "X-API-Key: $KEY" \
  -H "Content-Type: application/json" \
  -d '{"contract_text": "…"}'

        Full response shape (score, grade, risks, compliance, citations): see BLUEPRINT.md. A zero-dependency Python client ships in examples/client.py.
